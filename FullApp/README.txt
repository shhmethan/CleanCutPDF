Welcome to CleanCutPDF
CleanCutPDF is a fast, customizable desktop tool for cleanly splitting, renaming, and exporting PDFs using SPLIT HERE markers or client metadata. Version 1.6 introduces major usability upgrades, automatic updates, refined layout, and performance-focused polish.

🆕 What's New in Version 1.6:
✅ Auto-update system: No more installers — app replaces itself cleanly
📁 Quick Split output now uses dated folder structure (Quick Split Files/YYYY-MM-DD)
📄 Part filenames now include leading zeros (e.g., Part 01, Part 02) for better sorting
📊 Redesigned Logs tab with client/date "bubble" layout
🔤 Font + size changes now apply instantly to Logs tab
🎨 Theme switching is now seamless — all tabs remain visible
❌ Tab close (✖) now works immediately after opening new files
🔍 Preview buttons now hide correctly on first/last page
🖨️ Help tab redesigned with icons, printer/scanner guidance, and scanning tips
🔑 Keybinds now apply instantly across the app

⚙️ Core Features:
Drag-and-drop support in both Splitter and Quick Split
Smart "SPLIT HERE" page detection
Metadata-aware file naming (Client, Agency, Description, Date)
Undo Last Export (Ctrl+Shift+Z)
Optional blank page removal
"Make Client Folder" option on export
Auto session save + restore
Export logs with filtering, CSV output, and grouped layout
Font + theme customization
Floating keybind reference overlay (Show Keybinds)
Built-in debug console (Ctrl+Alt+D)
Guided tutorial runs on first launch

🖥️ System Requirements:
OS: Windows 10 or later (64-bit)
RAM: 2 GB minimum (4 GB recommended)
Disk Space: ~50 MB (plus PDF storage)

🔐 License Information:
CleanCutPDF requires a valid license key. Keys are verified online at first launch and stored locally for offline use. No telemetry or tracking is included. All user data stays on your device.
